# Attribution and scope

This research code evolved from the M4OE project described in the original source README:

> Wu, C., Shuai, Z., Tang, Z., Wang, L., & Shen, L. (2025). Dynamic Modeling of Patients, Modalities and Tasks via Multi-modal Multi-task Mixture of Experts. ICLR.

The supplied snapshot adapts that code for multimodal sentiment analysis and TCIF. The original source README names `tangzhengxu2001/m4oe` as its upstream repository. This attribution is preserved from local project records; upstream metadata has not been independently re-audited here.

Pretrained backbones, datasets and third-party dependencies retain their respective terms and are not distributed in this package. No new blanket license is assigned to the code by this packaging step.
