# MOSI 输入覆盖审计：dl01原始媒体补充

2026-10-02，只读审计。**dl01保留了MOSI原音频与人脸轨迹，音频6秒覆盖限制得到量化；未发现训练／验证集音频mask长度错位。** 这是一份数据审计，不是新训练结果。未改缓存、提交GPU任务或修改实验方案。

本报告补充此前Lab/c1“原媒体不可用”的记录：当时对那两台机器的结论保留，但不能再推广为整个项目无原媒体。此次dl01发现2199条音频、2199份人脸轨迹；缓存train/val/test覆盖1284/229/686，缺失0。测试集仅检查可用性与缓存ID覆盖，以下内容诊断限于训练／验证集。

所查`emotion_dataset.py::preprocess_audio`在重采样/降噪后保留`waveform[:max_len]`，即开头最多6秒；降噪函数显式保留波形长度。原音频全部16kHz、单声道int16。读取HuBERT配置的卷积kernel/stride，逐层计算截断后的有效token长度，与全部1513条训练／验证缓存audio_mask逐条一致。未见非法值、全零mask、非前缀mask或重复缓存ID。

超过6秒样本中，尾段占整段原波形平方能量的中位数为train16.05%、val16.65%；尾段/前6秒RMS比值中位数约.804/.706。因此尾段不能一概当作静音。**这些是原波形能量统计，不是VAD、语义或情感信息判定，也不是降噪后实际能量统计。**

训练弱非零样本的超6秒率16.86%（29/172），其余非零17.66%（187/1059），并未显示截断只集中于弱情感。验证相应为7/34和27/182，样本较少，不据此建立因果解释。strong组与other_nonzero重叠，不相加。

## 视觉采样

全部训练／验证轨迹可读，统一`T×112×112×3 uint8`。训练帧数最少7、中位94；验证最少24、中位91。四个均匀中心索引无重复。

| 检查 | train | val |
|---|---:|---:|
| 含全黑中心帧的样本 | 8/1284 | 2/229 |
| 四个中心全部全黑的样本 | 1 | 0 |
| 全黑中心帧数 | 14/5136 | 2/916 |
| 至少一对中心像素完全相同的样本 | 3 | 0 |

全黑定义为该采样帧全部像素精确为0；另检查全帧像素标准差<1，计数同样为14/2。只检查四个中心像素，不声称所有人脸帧无异常。

四个中心各取左／中／右共12槽，`context_ratio=.2`。训练1282条、验证229条各对应10个唯一帧索引，来自首尾边界重复；训练另有1条4个、1条8个唯一索引。**12槽不等于12个独立帧，边界重复也不直接等于实现错误。** 目前未验证脸部检测质量、原始帧时间映射或音画同步。

按数据集实际转写列读取文本，用本地RoBERTa tokenizer、不截断并包含special tokens计算长度；缓存长度与`min(length,128)`一致。这不能证明全部token ID或历史软件版本完全一致。未发现大范围文本截断证据。

对每个审计split各取6个均匀分布的位置，抽查audio/vision缓存特征，未见非有限值。**这是抽样，不是全缓存数值完整性验证，更没有重新编码核对原媒体与特征。**

## 可支持的下一步与边界

音频6秒→12秒单因素对照已有输入覆盖依据：按时长计算可补回大部分被截时长。若实施，应保持HuBERT、降噪、视觉采样、文本与融合配方不变，先核验新缓存长度/mask及资源成本，再比较模型表现。这里的12秒数字仅为覆盖计算，**未生成12秒缓存、未运行该实验，也不保证性能提升**。

dl01当前Python3.10.20、PyTorch2.4.0+cu121、Transformers5.1.0，核心导入通过，但未做GPU运行测试。环境不同于现有c1/Lab；当前未安装torchaudio，这对本批16kHz原音频无需重采样的长度检查无影响，但重建缓存前仍应核对依赖和预处理一致性。

## 方法与来源

[完整聚合记录](summary.json)由本次只读SSH审计实际输出转录而来，不包含原ID、转写、音视频、特征数组或机器私有路径。读取标签分割以核对样本，使用WAV原采样率和样本数计算时长；只对超6秒音频计算原波形能量；人脸数组以mmap检查形状和采样帧；缓存按完成分片的ID映射核对mask；没有对测试集按情感分组开展诊断。

已查看缓存生成配置及其指向的dataset/model源码。文件时间与缓存生成日期相邻，但文件时间不构成不可变版本证明。没有使用散列，也没有重建完整生成过程。

`python tools/check_mosi_input_audit.py`仅验证本公开聚合记录的计数和比例自洽，不代替远程原数据审计。
