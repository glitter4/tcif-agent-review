# TCIF：CMU-MOSEI 消融结果交接

更新时间：2026-09-15。状态：五组训练、五组评估和最终汇总均完成，退出码均为 0:0。本文仅依据本轮五种单模型配置及原定七点 eta 协议。

## 1. 接手先看

- 本轮固定论文选用的模型设置：Temporal Context Innovation Filtering（TCIF），滤波潜空间宽度128，门控隐藏宽度64，seed40。只做完整模型及四项消融，没有新增种子或容量搜索。
- 固定 eta=0.8、各自 best-ACC-7 checkpoint 时，完整模型为 **ACC-7=56.321%、MAE=0.49124、ACC2non0=87.094%、macro-F1non0=86.296%**。
- 去掉门控对七分类与回归影响最大；等权融合、共享滤波器也降低 ACC-7。普通上下文融合的 ACC-7 和二分类指标略高于完整模型，完整模型 MAE 更低，不能写成所有指标全面领先。
- 本轮完整模型是此次消融的对照。不能把历史单模型 ACC-7=56.536% 替换进本轮消融表。
- 完整结果为 5配置 × 2 checkpoint × 7 eta = **70点**；全部测试集样本数4659，非零标签子集3634。
- 汇总任务453664此前曾排队；截至本次检查已完成，不能继续沿用“汇总未完成”的旧状态。

## 2. 五种配置及实现边界

| 论文展示名称 | 命令/结果目录键 | 改动 | 融合模块及上下文预测头有效参数量 |
|---|---|---|---:|
| Full TCIF / 完整 TCIF | `full` | 原始双任务滤波、精度加权、门控及两项辅助监督 | 4,067,340 |
| Standard context fusion / 普通上下文融合 | `standard_context` | 有效邻居特征均值与局部特征拼接，经多层感知机产生残差 | 4,075,112 |
| Equal-weight fusion / 等权融合 | `equal_weight` | 仅将融合均值改为局部与先验各占一半 | 4,067,340 |
| Without continuation gate / 无门控 | `no_gate` | 去掉门控网络，有邻居时门值1，无邻居时0，同时关闭门控损失 | 3,999,498 |
| Shared task filter / 共享任务滤波器 | `shared_filter` | 两项任务使用同一个滤波模块，双查询和输出头仍独立 | 2,034,186 |

参数量是上述模块范围内的去重计数，不是整个模型参数量；本轮这些参数均可训练。

实现注意：
- 普通融合仍保留0.1权重的上下文辅助损失，作用于均值上下文的投影；门控网络和门控损失关闭。与完整模块参数差约0.19%，未通过无效参数填充。
- 普通融合不定义方差/innovation统计，其对应诊断字段为NaN，不代表最终预测有NaN；最终预测指标有效。不要将这些字段作为普通融合的机制证据。
- 等权融合保留方差网络、邻居评分、gate输入和辅助监督；诊断方差改为两者方差之和的四分之一，不再用它计算精度融合权重。
- 无门控同时移除了门控监督，其比较反映门控及其训练监督的整体贡献，不能单独归因于某一项门控公式。
- 共享滤波器确实共享参数，优化器不会重复更新；参数约减半，性能差异包含容量因素。
- 各配置保留一致的主干初始化随机数流程。代码测试包含完整路径与原始滤波器逐张量一致性、梯度、保存重建、共享参数和指标口径验证；此前9项模型测试和3项协议测试均通过。

## 3. 固定训练与评估协议

| 项目 | 设置 |
|---|---|
| 数据集/设备 | CMU-MOSEI；dl01的gpu01，A800-N分区，单GPU |
| 随机种子 | 40 |
| TCIF潜空间/门控隐藏宽度 | 128 / 64 |
| 邻域 | 同视频真实邻居，前后各一个，边界无效槽mask |
| batch / gradient accumulation | 64 / 4，有效batch256 |
| 最大epoch | 10 |
| 基础/门控学习率 | 均6e-5 |
| 专家路由学习率 | 4e-4 |
| 学习率调度/weight decay | none / .01 |
| dropout / attention dropout | .3 / 0 |
| 文本训练 | RoBERTa最后两层解冻，学习率比率.5，关闭text cache |
| 分类目标 | 七分类hard cross-entropy，权重.5 |
| 回归目标 | smooth L1 |
| 上下文辅助损失 | 权重.1，内部分类项权重.5 |
| 门控监督 | 权重.05，目标尺度tau=.75，初始化bias=2；无门控和普通融合关闭此项 |
| 训练时eta | .4 |
| 主表固定eta | .8 |
| 其他分支 | sign head、temporal contrast、OACR均关闭 |
| 确定性计算 | deterministic=False，与原设置一致 |

完整超参数保存在每个run的 `config.json` 及checkpoint同名JSON，不以本表替代完整配置。

checkpoint按测试集指标、在训练时eta=.4下分别选出 best-ACC-7 和 best-MAE；随后**每个checkpoint独立评估 eta={0,.2,.4,.6,.8,.9,1}**。不能因两个checkpoint选中同epoch而省略其中一份评估。

七点网格的汇总规则：
- best-ACC-7 checkpoint 内选择最高ACC-7，同分优先更低MAE；
- best-MAE checkpoint 内选择最低MAE，同分优先更高ACC-7；
- 每行所有指标来自同一个checkpoint和同一个eta，不将不同点的最佳指标拼接；
- 上述结果属于项目的test-selected开发协议，不是独立留出测试集的无偏泛化估计。

指标口径：
- ACC-7为全部4659条测试样本的七分类准确率，连续分数按half-away-from-zero四舍五入并截断到[-3,3]。
- MAE在全部测试样本上计算，保持原量纲。
- ACC2non0排除真实标签为0的样本；预测值>=0判为正类。
- F1non0为同一非零子集上正负两类F1的算术平均，即binary macro-F1，不是weighted-F1或单独正类F1。
- 准确率和F1在本文均为百分数。论文表可简称ACC-2/F1，但必须注明以上口径。

## 7. 结果可以支持什么

1. **门控对七分类和回归有贡献。** 固定eta=.8时，去掉门控令ACC-7下降0.859个百分点、MAE增加.01407；七点网格中调整eta后，完整模型在这些目标上仍有优势。但无门控的best-ACC-7点二分类指标更高，不能写成全部任务均受益。
2. **精度加权有七分类收益。** 固定eta=.8时，完整模型比等权融合高0.322个百分点ACC-7，MAE略低；二分类指标不占优。单次结果不能表述为统计显著改进。
3. **任务独立滤波更有利于当前ACC-7和MAE。** 共享后固定eta=.8的ACC-7下降0.537个百分点，但有效参数约减半，现有实验不能完全区分容量与任务分工的贡献。
4. **专门滤波与普通融合表现为取舍。** 普通融合固定eta=.8的ACC-7高0.107个百分点，并有更好的二分类指标；完整模型MAE低.00146。现有结果不支持“TCIF全面优于普通上下文融合”。
5. 尚未完成按同极性/跨极性邻域分组的专门分析。不要仅凭整体表格声称已证明情绪转折处的改善；中心排除、innovation输入的单独贡献也没有被本轮独立消融。

本轮完整模型选中epoch6，历史论文主结果选中epoch4；两次保存的训练设置一致，但非确定性运行轨迹不同。消融主表以本轮完整模型为对照，保留历史结果用于其原本的主实验记录。不要通过替换对照行扩大消融差距。
