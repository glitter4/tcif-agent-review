## 实现及证据边界

两次随机前向重用完全相同中心/邻居张量；仅dropout随机性不同。L1+.75 softCE+.05 gate完整任务损失取两视图平均，KL仅作用分类分布，双向各一半、batch mean；未约束回归等于分类期望。推理单次eval前向，结构不变。训练accuracy仍记录第一视图，loss parts是两视图平均，KL另存。

[执行源码与补丁](../../snapshots/mosi_rdrop_20260929/)；机制测试包括双边KL梯度、C1平均目标、无直接回归KL梯度、同输入随机dropout与eval稳定、独立采样器顺序。源迁移审计沿用[已完成源/目标审计](../mosei_to_mosi_20260927/README.md)。

这是单seed、test-selected开发结果，使用额外MOSEI监督；验证指标为所选checkpoint的附加诊断，不能消除测试选点偏差，也不证明多seed稳定性。与旧中断Lab D1、C1服务器历史S分开解释。未达到保护线即停止本轮，不自动搜索更大KL。
